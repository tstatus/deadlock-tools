      Match

      Farm

      Time-limited routes take a camp only when it pays more souls per second than the boxes it would replace, so faster clears mean more camps.

      Movement model

      Gap jumps get shorter the higher the landing and longer when landing lower. These three settings change which paths exist, so travel times are recomputed (about 40 s).

      Stamina

      Taller climbs use an air jump (1 stamina); longer gaps use a dash jump (2). Down dashes only happen when half a charge is spare. If you are short for a jump, the route waits for a recharge.

      Speeds

      Calibrate with in-game times

      Run a route in game from its start, breaking each box in order. Stop the timer when the last box breaks (or when you reach the finish), then record the time here.

        View

        Drag to orbit, right-drag to pan, wheel to zoom. Right-click the map to start or end the route there. WASD moves, Q/E down/up, hold Shift for speed. Follow path flies along the route: →/↓ next stop, ←/↑ previous, Esc to stop.
